Vision Assist 🚀
Real-time AI-based safety assistant using YOLOv8 and MiDaS for obstacle detection and depth-aware danger estimation.
🔍 Features
Real-time object detection (YOLOv8n)
Monocular depth estimation (MiDaS)
Distance-based danger scoring
Audio alerts for nearby hazards
Works with webcam input
🛠 Tech Stack
Python
Flask
PyTorch
Ultralytics YOLOv8
OpenCV
JavaScript (Frontend)
